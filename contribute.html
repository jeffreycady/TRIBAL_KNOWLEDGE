Suggest a change

Everything the app says comes from a question, an answer, and a source. This page shows how it's built and how to suggest a change. Edits go through GitHub, and a maintainer checks each one against its source before it goes live.

How to suggest a change
Takes about five minutes. You need a free GitHub account.
  1. Find the question or outcome you want to change below. Each one shows its id. Use the copy button to grab it.
  2. Click Edit in GitHub. It opens the data file for that topic. GitHub asks you to fork the repo the first time.
  3. Use the browser's search (Ctrl+F or Cmd+F) and paste the id to jump to it. Change only the text you're fixing. Keep the id the same.
  4. If you change an outcome, add or update its source with a link you have actually read. Replace a source rather than leaving it blank.
  5. Commit your change and open a pull request. In the description, say what changed, why, and link the source.
  6. A maintainer checks the wording and the source before it goes live. They may ask for changes first.
Rules for every change
These keep the content safe and checkable.
  • Every outcome needs a source you have read. Link the page itself, not a summary of it.
  • Don't diagnose, and don't give medication doses. Describe what to do and when to get help.
  • Actions should be specific and safe. If a symptom could be an emergency, route it to the emergency or clinician outcome.
  • Mental health pages keep the 988 crisis line visible. Don't remove it.
  • Plain language. Short sentences. If a claim comes from one study, say so.
